PRIMARY 3 MATHEMATICS LESSON PLAN: PLACE VALUE IN NUMBERS
=========================================================

Interactive Web-Based Lesson Planning System
Duration: 60 minutes | Ages 8-9 | Class Size: 30 students

FILES STRUCTURE:
----------------

Core Files:
• index.html - Main navigation hub and lesson overview
• styles.css - Shared CSS styling for all pages
• app.js - JavaScript for role switching, progress tracking, and interactivity

Section Files:
• learning-outcomes.html - ILOs aligned with Bloom's taxonomy
• pre-class-preparation.html - Pre-reading, diagnostic quiz with instant feedback
• teaching-activities.html - 4 CPA activities (Concrete-Pictorial-Abstract)
• assessment.html - Formative and summative assessment methods with rubrics
• alignment-matrix.html - Constructive alignment matrix linking outcomes/activities/assessments
• resources.html - Required materials, tech tools, external tool integration (Mentimeter, Kahoot, Khan Academy)
• differentiation.html - Support scaffolds and extension activities
• reflection.html - Success indicators and modification strategies
• slides.html - 10-slide presentation for classroom delivery

KEY FEATURES:
-------------

✓ Teacher/Student Role Switching
  - Click role switcher buttons to toggle between views
  - Teacher-only content: pedagogy notes, scaffolding tips, assessment rubrics
  - Student-only content: simplified instructions, self-assessment tools

✓ Interactive Quizzes
  - Diagnostic quiz with instant feedback (5 questions)
  - Click quiz options to see correct answers and explanations
  - Answers saved to localStorage

✓ Progress Tracking
  - Section completion tracked via localStorage
  - Persists across browser sessions

✓ External Tool Integration
  - Step-by-step instructions for Mentimeter (polling)
  - Step-by-step instructions for Kahoot (gamified quizzes)
  - Khan Academy video resources with clear access paths

✓ Responsive Design
  - Card-based interface
  - Works on desktop, tablet, and mobile
  - Collapsible sections for external tools

USAGE INSTRUCTIONS:
-------------------

1. Open index.html in a web browser
2. Use the role switcher to toggle between Teacher and Student views
3. Navigate to different sections using the quick links
4. Complete the diagnostic quiz in pre-class-preparation.html
5. Use slides.html for classroom presentation (10 slides)
6. Teachers: expand collapsible sections in resources.html for tool instructions

PEDAGOGY:
---------

• Scaffolded Instruction with CPA (Concrete-Pictorial-Abstract)
• I Do → We Do → You Do gradual release model
• Aligned with Hong Kong curriculum standards
• 80%+ mastery targets for exit tickets
