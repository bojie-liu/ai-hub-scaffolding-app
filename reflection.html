📊 Student Feedback Analysis

Exit Ticket Question:

"What part of the lesson helped you understand place value best?"

Expected Student Responses:

  • Base-10 blocks (concrete learners)
  • Place value chart (visual learners)
  • Working with a partner (social learners)
  • The receipt example (real-world connection)
  • Sentence frames (language scaffolds)
Teacher Action: Use the most popular response to plan the opening review in the next lesson.

🔄 Modification Strategies

If many students struggle with expanded form:

Add a second day of guided practice using number lines. Show how expanded form maps to the number line (e.g., 1325 = start at 1000, jump 300, jump 20, jump 5).

If advanced students finish quickly:

Include a "Challenge Corner" with 5-digit numbers, or introduce place value with decimals. Ask them to write real-world word problems using 4-digit numbers.

If real-time polling shows misconceptions:

Pause the lesson and return to concrete representation. Use more examples before moving to abstract. Adjust pacing accordingly.

If time runs short:

Prioritize Task 1 of independent practice. Assign Task 2 (Create a number) as homework. Ensure exit ticket is still completed.
