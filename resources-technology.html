💻 Resources & Technology

All digital tools, physical materials, and academic references required for this lesson.

Digital Tools

Moodle / Blackboard

Use: Pre-class diagnostic quiz; exit ticket submission

Setup Instructions +

  1. Log in to your institution's Moodle at your-institution.moodle.com
  2. Navigate to the course: Teaching Reading in English
  3. Open Week 3 Quiz: Scaffolding & ZPD Readiness
  4. Complete all 5 questions — adaptive feedback appears after each answer
  5. Submit before attending the class session

Mentimeter

Use: Misconception polls; real-time feedback; pre/post comparison

Setup Instructions +

  1. Go to www.mentimeter.com and sign up for a free account
  2. Click New Presentation and select Scales as question type
  3. Add three statements (see Teaching Activities page for exact wording)
  4. Set the scale labels to Strongly Disagree → Strongly Agree
  5. Before class, copy the 6-digit voting code or generate a QR code
  6. Display the code at the start of the Introduction phase
  7. Reuse the same presentation at Closure to compare pre/post results

Purpose: Reveal and then track conceptual change in real time

Padlet

Use: Group annotation gallery; sharing best annotations whole-class

Setup Instructions +

  1. Go to padlet.com and create a free account
  2. Click Make a Padlet and choose the Wall layout
  3. Title it: Group Annotation Gallery – [Date]
  4. Create one column per group cluster (e.g., Groups 1–6, Groups 7–12, Groups 13–18)
  5. Enable Comments so the teacher can add annotations to posts
  6. Generate a QR code via Share → QR Code and display it during Part B
  7. Each group Scribe posts: (a) one puzzling phrase, (b) one connection, (c) one new understanding

Purpose: Make group thinking visible for whole-class synthesis

Google Slides / PowerPoint

Use: Think-aloud modelling text (Text A); slides for key concepts

Setup Instructions +

  1. Prepare Text A (300–400 words) as a full-screen slide
  2. Leave wide margins on both sides so you can type annotation symbols live
  3. Use a font size of at least 24pt for classroom visibility
  4. Add the Annotation Code Card as a reference slide
  5. Use a high-contrast colour scheme (dark text on white background)

Physical & Teacher-Made Materials

  • Text A: Teacher-generated academic text for modelling think-aloud (prepared in advance)
  • Text B: 3–4 differentiated text options for guided group annotation (300–500 words each)
  • Annotation Code Card: One printed card per group (6 symbols and their meanings)
  • Role Cards: Leader, Scribe, Clarifier, Connector, Reporter (laminated cards for reuse)
  • Large sticky notes / marker pens: Optional for non-digital group annotation

Academic References

  • Gibbons, P. (2002). Scaffolding Language, Scaffolding Learning. Portsmouth, NH: Heinemann. Required pre-reading
  • Reading Rockets: Think-Aloud Strategy. https://www.readingrockets.org/strategies/think_aloud Required video
  • Vygotsky, L. S. (1978). Mind in Society: The Development of Higher Psychological Processes. Cambridge, MA: Harvard University Press.

Teacher Preparation Checklist

  • ☐ Pre-class quiz activated on Moodle (Week 3 module)
  • ☐ Mentimeter presentation created with 3 scales
  • ☐ Padlet board created and QR code printed
  • ☐ Text A prepared on Google Slides (large font, wide margins)
  • ☐ Text B options printed for each group (3–4 differentiated versions)
  • ☐ Annotation Code Cards printed (15–18 copies)
  • ☐ Role Cards prepared (5 roles × 18 groups)
  • ☐ Mixed-ability group assignments ready (based on quiz data)
  • ☐ TAs briefed on scaffolding questions for group circulation
