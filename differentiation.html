Movement-Based Activities

  • Physical place value: Students stand in line representing digits in a number
  • Action response: Stand up when you hear a digit in the hundreds place
  • Block building: Extended time manipulating base-10 blocks
  • Walk the number line: Step along a floor number line to show place value

♿ Accessibility Accommodations

Visual Supports

  • Large-print worksheets (18pt font minimum)
  • High-contrast place value charts
  • Color-coded places (thousands=blue, hundreds=green, etc.)

Auditory Supports

  • Verbal instructions for every visual
  • Closed captions on videos
  • Audio recording of worksheet instructions

Physical Accommodations

  • Larger manipulatives for fine motor challenges
  • Digital place value tools for alternative input
  • Extended time for written work
