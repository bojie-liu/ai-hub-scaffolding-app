Learning Outcomes

Intended Learning Outcomes (ILOs)

Using Bloom's Taxonomy action verbs; aligned with Scaffolded Instruction progression

1

Identify

Bloom's Level: Remembering

Identify the value of digits in 4-digit numbers using base‑10 blocks and place value charts.

Scaffolded Instruction: Teacher provides concrete representation during "I do" phase
2

Explain

Bloom's Level: Understanding

Explain the relationship between adjacent place values (e.g., 1 ten = 10 ones) using concrete models.

Scaffolded Instruction: Guided practice with teacher support during "We do" phase
3

Apply

Bloom's Level: Applying

Apply place value knowledge to compare and order 4-digit numbers.

Scaffolded Instruction: Independent practice during "You do" phase
4

Create

Bloom's Level: Creating

Create a 4-digit number that meets given conditions (e.g., "largest number with 3 in the hundreds place") during independent practice.

Scaffolded Instruction: Student-driven creation with extension challenges for higher-order thinking

Scaffolded Instruction Connection

Each outcome builds on prior knowledge, moving from teacher-led recognition to student-driven creation. This progressive release of responsibility ensures all learners can access the content at their level.
