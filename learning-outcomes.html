🎯 Intended Learning Outcomes (ILOs)

Current Role: Student

📋 What You Will Learn

By the end of this lesson, you will be able to:

ILO 1: Identify Place Value Remember/Understand

Identify and state the place value (hundreds, tens, ones) of each digit in a 3-digit number up to 999.

Example: In the number 456, the digit 4 is in the hundreds place, 5 is in the tens place, and 6 is in the ones place.

Teaching Note: This foundational ILO builds on students' prior 2-digit place value knowledge. Use base-10 blocks in the concrete phase to make hundreds tangible.

ILO 2: Represent Numbers Apply

Represent 3-digit numbers using base-10 blocks, place value charts, and expanded form (e.g., 327 = 300 + 20 + 7).

Example: The number 327 can be shown as:
• 3 hundreds blocks + 2 tens rods + 7 ones units
• 300 + 20 + 7

ILO 3: Compare and Order Numbers Analyze

Compare and order 3-digit numbers using place value reasoning (e.g., using >, <, =).

Example: To compare 328 and 342, first look at the hundreds (both have 3), then look at the tens (2 vs 4). Since 2 < 4, we know 328 < 342.

ILO 4: Apply to Real-World Problems Apply

Apply place value knowledge to solve real-world grouping problems (e.g., bundling items into hundreds, tens, and ones).

Example: If we have 287 pencils to bundle, we can make 2 bundles of 100, 8 bundles of 10, and have 7 single pencils left.

ILO 5: Explain Your Reasoning Understand/Explain

Explain your reasoning using accurate mathematical language (e.g., "The digit 4 in 456 represents 4 hundreds, or 400.").

Assessment Focus: Listen for precise language during partner work. Use sentence frames: "The digit ___ in the ___ place represents ___."

🔗 Pedagogy Link: Scaffolded Instruction

These ILOs are deliberately sequenced to follow scaffolded progression:

  • Foundation: Identification (ILO 1)
  • Representation: Multiple forms (ILO 2)
  • Higher-order: Comparison and application (ILOs 3-4)
  • Communication: Mathematical language (ILO 5)
