📌 Using This Matrix for Planning Teacher Only

This matrix is a living planning tool. When adapting this lesson for a new cohort:

  • Start from ILOs: if you add or modify an ILO, trace its row to ensure an activity and assessment match.
  • Check for orphaned activities: any activity without a clear ILO link should be cut or repurposed.
  • AI integration column: if AI tools change (e.g., new LLM), update the AI Integration column to reflect new capabilities or risks.
  • Use the filter (student view) to preview what students see when focusing on a specific strand.
