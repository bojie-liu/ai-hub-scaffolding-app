# Place Value in Numbers - Primary 3 Mathematics Lesson Plan

## Overview
This is an interactive, comprehensive lesson plan website for teaching place value (up to 10,000) to Primary 3 students (ages 8-9). The lesson implements **Scaffolded Instruction** pedagogy and follows **Constructive Alignment** principles.

## Lesson Details
- **Duration**: 60 minutes
- **Subject**: Primary 3 Mathematics
- **Topic**: Place Value in Numbers (up to 10,000)
- **Class Size**: 30 students
- **Pedagogy**: Scaffolded Instruction (I do → We do → You do)
- **Language**: English

## Files Structure

### Main Entry Point
- **index.html** - Homepage with navigation to all sections and progress tracking

### Lesson Sections
- **learning-outcomes.html** - Intended Learning Outcomes using Bloom's Taxonomy
- **pre-class.html** - Pre-class preparation with interactive pre-test
- **introduction.html** - 8-minute introduction with hook activity
- **development.html** - 42-minute development activities (4 scaffolded phases)
- **synthesis.html** - 10-minute synthesis & closure with post-test
- **assessment.html** - Formative and summative assessment methods with interactive quizzes
- **alignment.html** - Constructive alignment matrix
- **resources.html** - Required resources, technology, and external tool integration
- **differentiation.html** - Strategies for diverse learners
- **reflection.html** - Teacher reflection and improvement strategies
- **slides.html** - 10-slide presentation for classroom use

### Shared Files
- **styles.css** - All CSS styles (responsive, card-based design)
- **app.js** - JavaScript for interactivity, progress tracking, and localStorage

## Features

### Interactive Elements
- ✅ Interactive quizzes with instant feedback
- 📊 Progress tracking using localStorage
- 👥 Teacher/Student role differentiation
- 🎬 10-slide presentation with navigation
- 📝 Exit tickets and reflection forms
- 🔗 External tool integration (Mentimeter, Khan Academy, Kahoot, Padlet)

### Pedagogical Structure
- Scaffolded Instruction (I do → We do → You do)
- Bloom's Taxonomy alignment (Remembering → Creating)
- Constructive Alignment (outcomes ↔ activities ↔ assessment)
- Differentiation for struggling learners, ELL, advanced students

### Technology Integration
- Google Classroom for LMS
- Mentimeter for real-time polling
- Khan Academy for pre-class video
- Kahoot for gamified practice
- Padlet for collaborative reflection

## How to Use

1. Open **index.html** in a web browser
2. Select your role (Teacher or Student)
3. Navigate through sections using the card grid
4. Complete interactive activities and quizzes
5. Progress is automatically tracked in localStorage

## For Teachers
- All teacher notes are visible only in Teacher mode
- Use the presentation slides.html for classroom projection
- External tool setup instructions included in resources.html
- Differentiation strategies provided for all learner types

## For Students
- Complete pre-class preparation before the lesson
- Follow the scaffolded activities in sequence
- Practice with interactive quizzes
- Submit exit tickets and reflections

## Browser Compatibility
Works best in modern browsers (Chrome, Firefox, Safari, Edge)

## Data Storage
All progress, quiz results, and reflections are stored locally using localStorage. No server required.
