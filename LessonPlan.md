# Full Lesson Plan: The Modern Software Developer

## 1. Intended Learning Outcomes (ILOs)
1. Analyze how AI-powered tools are transforming traditional software engineering practices
2. Evaluate the ethical and technical challenges of AI integration in development workflows
3. Design a basic AI-enhanced development workflow demonstrating problem decomposition
4. Collaborate effectively to identify appropriate AI tool application scenarios

## 2. Pre-Class Preparation
**Pre-reading**:
- Video: "The AI Coding Revolution" (12 mins) covering GitHub Copilot and Amazon CodeWhisperer
- Selected chapter from "AI for Software Engineering" textbook (pp. 23-41)

**Pre-test**:
[Quiz: AI Impact on Development with 8 questions]
- Example: "What proportion of code do leading AI tools auto-complete in IDEs? (a) 10-20% (b) 30-45% (c) 60-75% (d) 80-95%"

**Guiding Questions**:
1. How does AI shift the developer role from "coder" to "architect"?
2. What limitations might you expect with current AI code generation tools?
3. Identify one ethical concern with AI-generated code reuse

## 3. Teaching & Learning Activities

### Introduction (10 mins)
- **Hook**: Live demo of GitHub Copilot generating complete functions from comments
- **Poll**: "How familiar are you with AI coding tools?" using Mentimeter (anonymous)
- **Pre-test Discussion**: Address top misconceptions, particularly around AI code originality
- **Real-world Connection**: Case of Microsoft's AI-powered Azure DevOps tools improving team productivity

### Development (65 mins)

#### Segment 1: AI Tool Landscape (20 mins)
- **Interactive Lecture**: Evolution of development workflows with timeline visualization
- **Think-Pair-Share**: Compare traditional vs AI-enhanced debugging approaches
- [Animated Illustration: Code Generation Workflow] showing prompt → generation → modification cycles
- [Concept Map Template] distributed for planning AI integration stages

#### Segment 2: Hands-on Case Study (30 mins)
- **Group Work (6 groups of 5)**: Analyze real startup's migration to AI tools
  - Scenario: Scaling from 5 to 50 developers while maintaining code quality
- **Structured Prompts**:
  1. Identify integration points in planning phase
  2. Evaluate testing workflow modifications
  3. Propose code review process adaptations

#### Segment 3: Ethical Analysis (15 mins)
- **Debate**: "AI tools democratize vs devalue software skills" - randomized role assignments
- **Polling**: Before-after voting to measure perspective shifts
- **Digital Flashcards**: Key terms quiz (e.g., synthetic datasets, code plagiarism)

### Synthesis & Closure (15 mins)
- [Post-test: AI Challenge Assessment with 6 questions]
- One-Minute Paper: "What's one traditional practice all teams should keep despite AI adoption?"
- Preview next session on AI in QA testing and preview of continuous integration tools

## 4. Assessment Methods

### Formative
- Pre/post-test comparison (knowledge gain tracking)
- Group work observation rubric (collaboration, technical reasoning)
- Polling responses across demographic clusters
- Exit tickets analyzing key insights

### Summative
**Assignment**: "AI Integration Strategy Proposal" (Due next week)
- Requirements:
  - 1500-word analysis of hypothetical company's AI adoption
  - Minimum 3 tool comparisons with technical justification
  - Ethical considerations section
- [Rubric: 30% technical accuracy, 25% innovation potential, 25% ethical analysis, 20% presentation]

## 8. Reflection & Improvement
**Success Indicators**:
- 70% average on post-test vs 40% pre-test
- 80% attendance in group work phases
- Assignment performance above 65% threshold

**Feedback Methods**:
- Mid-course anonymous survey
- Debrief interview with TA observations
- Post-lesson focus groups with student representatives

**Modification Plans**:
- Adjust case study complexity based on demographic patterns
- Create supplemental AI ethics module if ethical dilemma responses insufficient
- Develop more scaffolded coding challenges for novice developers

---

This lesson plan implements a cognitive apprenticeship model, modeling expert reasoning about AI tool selection while gradually transferring responsibility to students through structured practice. The formative assessments build scaffolding for the summative assignment, with the concept map specifically connecting Bloom's Understand and Apply levels to the Create-level requirements of the proposal.
