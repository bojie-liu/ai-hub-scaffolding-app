## Intelligent TPACK Lesson Plan

### 1. Intended Learning Outcomes (ILOs)
1. Analyze the seven components of Intelligent TPACK and their intersections
2. Evaluate existing lesson plans for strengths/weaknesses in technology integration using Intelligent TPACK framework
3. Apply intelligent design principles to create innovative technology-enhanced pedagogical approaches
4. Synthesize disciplinary content knowledge with educational technology tools to solve authentic teaching problems
5. Critique ethical considerations of AI integration in teaching practice

### 2. Pre-Class Preparation
- **Video**: "[TPACK Framework Explained](https://www.youtube.com/watch?v=ABC123)" (7min) + OECD 2021 Report excerpt: "Artificial Intelligence in Education" (2 pages)
- **Pre-test**: 10-question quiz (Google Forms) on TPACK basics and AI integration challenges
- **Guiding Questions**:
  1. How do you currently integrate technology in your teaching practice?
  2. What do you consider the "intelligence" components in technology-based teaching?
  3. What ethical dilemmas might arise from AI tools in classrooms?

### 3. Teaching & Learning Activities

#### Introduction (27 min)
- **Hook**: Project image of a traditional classroom vs. AI-integrated classroom side-by-side
  - Think-pair-share: "Which elements would you want to maintain/transform in these environments?"
- **Pre-test Review**: 5min overview of common misconceptions shown in pre-test responses using Mentimeter word cloud
- **Real-world Connection**: Case scenario "Ms. Chen's Tech Dilemma"- a teacher struggling to engage students with current tech tools

#### Development Activities (135 min)
**Activity 1**: Interactive Lecture & Graphic Organizer (30min)
[Animated Illustration: Intelligent TPACK components]
- Co-construct digital concept map using Padlet displaying framework's 7 components
- Scaffolding: Worked example analyzing historical TPACK application

**Activity 2**: Case Analysis Roundtables (45min)
- 5 case studies (Google Docs) showing varying degrees of TPACK implementation
- Groups rotate through stations every 8min, using [Case Analysis Template](#case-analysis-template) to:
  1. Identify TPACK components used
  2. Suggest enhancements using intelligent tools
  3. Propose ethical considerations

**Activity 3**: AI Toolkit Workshop (40min)
- Demonstration of 4 intelligent tools:
  [Tool 1: Canva for Education] (visual content creation)
  [Tool 2: Quizizz AI] (adaptive assessments)
  [Tool 3: Genially] (interactive presentations)
  [Tool 4: Edpuzzle] (interactive video)
- Groups create 3-5 min demos integrating specific content/pedagogy needs

**Activity 4**: Peer Teaching Carousel (20min)
- 6 rotating stations with focus areas:
  1. Content/TK intersection in STEM
  2. Adaptive instruction in language learning
  3. Ethical use frameworks
  4. Assessment with AI tools
  5. Student engagement design
  6. Professional development strategies

**Breaks**: 10min mid-section break + 5min hydration break

#### Synthesis & Closure (18 min)
- **Post-test**: 10-item adaptive quiz with immediate individual feedback (Mentimeter)
- **Reflective Discussion**: "How might your teaching philosophy need to evolve to incorporate intelligent technologies?"
- **Preview**: Assignment prompt for next session: "Designing a 21st Century Professional Learning Plan"

---

### 4. Assessment Methods

#### Formative Assessment
- Participation in roundtable discussions (tracked via Padlet interaction)
- Quality of digital demonstrations
- Immediate feedback from adaptive post-test
- Exit ticket: "Identify one technology misconception you now understand differently"

#### Summative Assessment
**Assignment**: Design a technology-integrated lesson plan using Intelligent TPACK (3 pages)
**Rubric**:
| Component | Excellent (4) | Proficient (3) | Developing (2) | Needs Work (1) |
|----------|---------------|----------------|----------------|----------------|
| TPACK Framework Integration | All 7 components clearly identified and interconnected | 5+ components explained with minor gaps | 3-4 components addressed | <3 components incorporated |
| Intelligent Design Elements | 3+ AI tools intentionally connected to pedagogy | 2 tools with clear rationale | 1 tool with basic justification | Tools mentioned without explanation |
| Ethical Reflection | Multifaceted analysis of equity/privacy issues | Basic ethical considerations addressed | Surface-level acknowledgment | No ethical analysis provided |
| Innovation & Practicality | Creatively combines content/technology | Effective application with minor limitations | Limited innovation, some feasibility issues | Unrealistic implementation plan |

### 7. Differentiation & Inclusivity
- **Supports**:
  - Visual guides for auditory components
  - Multiple access points to digital materials (mobile/web/desktop)
- **Extensions**: Advanced learners analyze UNESCO's AI guidelines
- **Accommodations**:
  - Closed captioning for videos
  - Alternative formats for all digital materials
- **Language**:
  - Bilingual terminology flashcards
  - Plain language summaries for technical concepts

---

### 8. Reflection & Improvement
- **Indicators**:
  - 80% participation in peer teaching carousel
  - 70% average score on post-test
  - 90% submission rate for summative assignment
- **Feedback**:
  - Mid-lesson pulse check (Mentimeter)
  - Post-lesson survey with Likert scale questions
- **Modifications**: Adjust breakout group sizes based on engagement data; update case studies annually with current tech examples
