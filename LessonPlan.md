# The Modern Software Developer - Lesson Plan
**Duration**: 90 minutes
**Student Level**: First-year undergraduates
**Class Size**: 30 students
**Topic**: Impact of AI on Software Development Workflows

---

### 1. Intended Learning Outcomes (ILOs)
By the end of this lesson, students will be able to:
1. **Analyze** the impact of AI tools on traditional software development workflows using case studies.
2. **Evaluate** the effectiveness of AI-powered code generation tools compared to manual coding approaches.
3. **Apply** iterative AI-assisted development workflows (plan → generate → modify → repeat) to solve mini coding challenges.
4. **Compare** ethical considerations and productivity gains in AI-enhanced vs legacy development models.

---

---

### 3. Teaching & Learning Activities

#### **Introduction (12 min)**
- **Hook (5 min)**: Poll with [Mentimeter]: "Do you think AI tools will eliminate developers? Agree/Neutral/No." Display live results.
- **Pre-Test Review (5 min)**: Highlight 2 common misconceptions from pre-test data (e.g., "AI replaces creativity entirely").
- **Real-World Link (2 min)**: Show GitHub CoPilot usage statistics (20% faster code production) and Microsoft's low-code/no-code platforms.

---

#### **Development Activities (66 min)**

**Activity 1: AI Workflow Demo (15 min)**
- **Interactive Lecture**: Live demonstration of GitHub Copilot for generating a Python function with inputs/outputs.
- **Think-Pair-Share**: "What are 2 advantages of this iterative workflow for beginners vs experts?"

**Activity 2: Group Case Study Analysis (20 min)**
- **Small Groups (4 per group)**: Analyze [Case Study: AI Adoption in a 50-person startup](insert PDF)
- **Structured Prompts**:
   - Identify productivity gains in requirements → code transitions
   - Highlight a scenario where AI output requires debugging

**Activity 3: Hands-On Practice (25 min)**
- **Starter Task**: Use [Replit + Copilot] to generate a Flask API endpoint (pre-configured template)
- **Scaffolding**:
   1. Instructors provide step-by-step plan (graphic organizer)
   2. Students modify generated CRUD operations (color-coded error highlighting)

**Activity 4: Ethics Debate (6 min)**
- **Structured Discussion** (via Padlet): Post 1 risk and 1 benefit of democratized coding in healthcare software contexts.

---

#### **Synthesis & Closure (12 min)**
- **Post-Test Comparison (5 min)**: Repeat 3 key pre-test questions to measure knowledge gains.
- **Reflective Discussion (5 min)**: "In 1 sentence, how would you explain AI's role in software accessibility to a non-techie friend?"
- **Next Session Preview (2 min)**: Introduce version control integration with AI tools.

---

### 4. Assessment Methods

**Formative**:
- Pre-/Post-test comparison (3 repeated questions on productivity metrics)
- Padlet ethic debate contributions (evaluated for critical thinking)
- Live Copilot code submission logs (tracked for workflow application)

**Summative**:
- **Take-Home Case Study Analysis (Due Next Week)**:
   Analyze an AI tool's impact on a specific industry (500 words + rubric)
   **Rubric Criteria**:
   - Depth of technical evaluation (25%)
   - Ethical implications addressed (20%)
   - Workflow diagram clarity (15%)

---

### 5. Constructive Alignment Matrix

| Learning Outcome | Teaching Activity | Assessment Method |
|------------------|-------------------|-------------------|
| Analyze impact | Workflow Demo + Case Study | Case Study Analysis |
| Evaluate tools | Hands-On Practice | Copilot code submission |
| Apply workflows | Guided practice with debugging | In-class coding task |

### 6. Required Resources & Technology
- **LMS**: Canvas for distributing pre-class materials
- **Interactive Tools**: Mentimeter (polls), Kahoot (pre-test), Padlet (debate), GitHub Copilot/Replit
- **Physical Materials**: Printed case study handouts (for accessibility)

---

### 7. Differentiation & Inclusivity
- **Support**: Pair non-native English speakers with visual learners for case studies
- **Extensions**: Advanced students research prompt engineering for optimized code generation
- **Accommodations**: Provide keyboard-free Copilot alternatives for motor-challenged students

---

### 8. Reflection & Improvement
- **Success Indicators**: Post-test score improvement >40%, 85% Copilot task completion
- **Feedback Mechanism**: Exit ticket: "What surprised you most about AI's capabilities?"
- **Future Tweaks**: If students struggle with tool access, pre-load cloud IDE templates
