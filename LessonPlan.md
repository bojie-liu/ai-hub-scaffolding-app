# AI-Powered Software Engineering: From Manual Coding to Intelligent Workflows

## 1. Intended Learning Outcomes (ILOs)

By the end of the lesson, students will:
- **Analyze** the evolution of software engineering methodologies from manual coding to AI-powered workflows
- **Apply** AI-assisted development tools (e.g., GitHub Copilot) to solve basic coding challenges
- **Evaluate** ethical considerations and technical limitations of AI in software engineering
- **Create** a documented prototype using AI-generated code, modified through iterative refinement

## 2. Pre-Class Preparation

- **Video & Reading**: Watch 10-minute TED-Ed video "How AI is reshaping programming" + short article from IEEE Spectrum on AI's impact on coding accessibility
- **Pre-Test**: 5-question quiz (via Canvas) on foundational concepts (e.g., "What percentage of code in 2025 will be auto-generated according to Gartner?")
- **Guiding Questions**: "How might AI change the role of software engineers in 10 years?" + "What are potential risks of over-reliance on AI tools?"

## 3. Teaching & Learning Activities

### Introduction (20 min)
- **Hook**: 3-minute demo of GitHub Copilot writing a basic sorting algorithm
- **Poll**: "How many of you have used AI code assistants?" using Poll Everywhere
- **Discussion**: Link pre-test results to lesson objectives, addressing misconceptions (e.g., "AI replaces coders" vs "augments productivity")

### Development Activities (130 min)

#### Mod 1: Foundations of AI Development (30 min)
- Interactive lecture with MentiMeter word clouds: Map traditional vs AI-powered workflow terms
- Case Study Analysis: Analyze 2023 Microsoft study showing 55% productivity increase among Copilot users
- Think-Pair-Share: "What software engineering principles remain unchanged?"

#### Mod 2: Hands-On Practice (60 min)
- Live Coding Workshop in pairs (using classroom laptops with Copilot trial):
  - Challenge 1: Generate basic API with OpenAPI and AI comments
  - Challenge 2: Implement a CRUD system with minimal human input
  - Scaffolded: Provide starter template and reference video
- Peer Teaching: 5-minute speed presentations on unique AI tools (selected from pre-class research)

#### Mod 3: Critical Analysis (40 min)
- Debate: Randomly assign pro/con positions for "AI will democratize software engineering by 2027"
- Ethical Framework Exercise: Identify bias examples in training data using IBM's AI Fairness 360 toolkit demo
- Poll: "Should AI-assisted coding exams count as independent work?"

### Synthesis & Closure (30 min)
- Post-Test comparison with pre-test results
- One-Minute Paper: "What surprised you most about AI's capabilities?"
- Preview: Introduction to next module on prompt engineering for developers

## 4. Assessment Methods

### Formative Assessment
- Real-time polling responses during debates
- Workshop rubric evaluating code quality and documentation
- Exit ticket self-assessment on ILO proficiency

### Summative Assessment
- **Prototype Presentation (20%)**:
  - Submit annotated code with GitHub commit history showing iterative improvements
  - Graded on technical accuracy (40%), critical reflection (30%), and human-AI collaboration demonstration (30%)

## 6. Required Resources & Technology

- Pre-installed AI extensions (GitHub Copilot, Amazon CodeWhisperer)
- LMS integration (Canvas/Moodle) for materials/polls
- Projector for live demos and Mentimeter/Poll Everywhere
- GitHub classroom for code submissions
- Accessible PDF guides for screen readers

## 7. Differentiation & Inclusivity

- Provide closed captions for all videos
- Offer text-based alternatives for live coding (pre-generated GIF sequences)
- Advanced learners: Challenge bonus points for implementing accessibility checks
- Multilingual students: Provide glossaries in 8 languages + AI translation tools

## 8. Reflection & Improvement

- Success Metrics: 75% mastery in post-test improvements + prototype code quality
- Feedback: Anonymous LMS survey on tool accessibility and pace
- Modifications: Adjust workshop scaffolding based on observed skill gaps

### Quiz: Foundations of AI in Software Engineering - 10 MCQ
1. What percentage of code in 2025 will be auto-generated according to Gartner?
   - A) 10%  B) 30%  C) 50%  D) 80%
   - **Answer: C**

2. Which of the following is an AI-powered code assistant?
   - A) Notepad++  B) GitHub Copilot  C) Microsoft Word  D) Adobe Photoshop
   - **Answer: B**

3. What was the reported productivity increase in the 2023 Microsoft study on Copilot users?
   - A) 25%  B) 40%  C) 55%  D) 70%
   - **Answer: C**

4. Which ethical concern is most associated with AI-generated code?
   - A) Code efficiency  B) Bias in training data  C) Color scheme choices  D) File naming conventions
   - **Answer: B**

5. What is the primary function of IBM's AI Fairness 360 toolkit?
   - A) Code compilation  B) Detecting and mitigating bias  C) Database management  D) UI design
   - **Answer: B**

6. Which software engineering principle remains unchanged despite AI tools?
   - A) Manual syntax checking  B) Understanding user requirements  C) Hand-writing boilerplate  D) Memorizing API syntax
   - **Answer: B**

7. What is a potential risk of over-reliance on AI coding tools?
   - A) Faster compilation  B) Reduced critical thinking  C) Better documentation  D) Improved testing
   - **Answer: B**

8. In the AI-assisted workflow, what role does the developer primarily play?
   - A) Typing all code manually  B) Reviewing and guiding AI-generated code  C) Avoiding all coding  D) Only writing documentation
   - **Answer: B**

9. What does "democratization of software engineering" mean in the context of AI?
   - A) Only experts can code  B) Making coding accessible to more people  C) Eliminating all programmers  D) Increasing software costs
   - **Answer: B**

10. Which of the following best describes the relationship between AI and software engineers?
    - A) Replacement  B) Competition  C) Augmentation  D) Elimination
    - **Answer: C**

### Case Study: GitHub Copilot Impact on Team Productivity - 3 Scenarios with Discussion Questions

**Scenario 1: Startup Acceleration**
A 3-person startup uses GitHub Copilot to build their MVP. They report completing the project in 6 weeks instead of the estimated 10 weeks.
- Discussion: What factors beyond AI might have contributed to this speed increase? How would you verify the AI's actual contribution?

**Scenario 2: Enterprise Integration Challenges**
A large corporation rolls out Copilot to 500 developers. 60% report productivity gains, but 25% say the tool slows them down due to incorrect suggestions.
- Discussion: Why might AI tools have mixed results in enterprise settings? What support structures would help?

**Scenario 3: Learning and Skill Development**
A university course integrates Copilot into programming assignments. Students complete tasks faster but score lower on unassisted exams.
- Discussion: How should educators balance AI tool usage with fundamental skill development?

### Template: AI-assisted Code Submission Rubric - 5 Criteria with Scoring Guide

| Criteria | Excellent (5) | Proficient (4) | Developing (3) | Beginning (2) | Inadequate (1) |
|----------|---------------|----------------|----------------|----------------|-----------------|
| Technical Accuracy | Code runs perfectly, handles edge cases | Code runs with minor issues | Code runs but lacks edge cases | Code has significant bugs | Code does not run |
| Critical Reflection | Deep analysis of AI's role & limitations | Good analysis with minor gaps | Surface-level reflection | Minimal reflection | No reflection |
| Human-AI Collaboration | Clear evidence of iterative refinement | Some evidence of refinement | Limited iteration | Mostly unmodified AI output | Pure AI output |
| Documentation | Comprehensive comments & explanations | Good documentation | Basic documentation | Minimal documentation | No documentation |
| Code Quality | Clean, efficient, follows best practices | Mostly clean code | Functional but messy | Poor code structure | Unstructured code |
