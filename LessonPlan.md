# University Lesson Plan: The Modern Software Developer

**Duration**: 90 minutes
**Class Size**: 30 students
**Topic**: AI-Enhanced Software Development Workflows
**Language**: English

---

## 1. Intended Learning Outcomes (ILOs)
By the end of this lesson, students will be able to:
1. **Analyze** how AI tools address traditional software engineering challenges (e.g., debugging, code generation).
2. **Evaluate** the effectiveness of AI-powered code assistants like GitHub Copilot using real-world scenarios.
3. **Apply** an iterative "plan, generate, modify" workflow to solve a simple coding problem with AI assistance.
4. **Critique** ethical and practical limitations of AI-driven software development.

---

## 2. Pre-Class Preparation
**Pre-Reading (10–15 minutes):**
- [Text: *"The Future of Code is AI"* by GitHub](https://github.blog/2022-09-06-ai-pairs-with-developers/)
- [Video: *"GitHub Copilot in 1 Hour"* (YouTube, 10 min)](https://www.youtube.com/watch?v=hDg58fA1Ack)

**Pre-Test (5 questions, via LMS):**
1. TRUE/FALSE: AI code assistants can generate 100% fully functional programs without human intervention.
2. Short answer: Name one ethical concern associated with AI-generated code.
3. Multiple choice: Which of these tasks can an AI code assistant NOT perform?
   A) Autocomplete functions
   B) Debug existing code
   C) Design app UX layouts
4. Rating scale: Rate your confidence in using AI tools for coding on a 1–5 scale.

**Guiding Questions:**
- How might AI tools change the skill sets required for beginner programmers?
- When would you prefer manual coding over using an AI assistant?

---

## 3. Teaching & Learning Activities

### **Introduction (10 minutes)**
**Hook:**
Show a side-by-side comparison:
- [Animated illustration: "Manual vs. AI-Assisted Debugging"](https://via.placeholder.com/600x300?text=Interactive+Debugging+Demo))
Ask: *"Can a neural network write error-free code faster than a human?"*

**Pre-Test Review & Misconceptions:**
- Display common misconceptions (e.g., "AI replaces programmers") using Mentimeter live word cloud.
- Show real-world data: GitHub Copilot saves developers **40% time** on average (cite study).

---

### **Development (60 minutes)**

#### **Interactive Lecture: AI's Impact on Software Workflows (15 mins)**
- **Scaffolded Segments**:
  1. Evolution of software engineering: 0–1 code creation → augmentation (2000s) → iterative AI workflows.
  2. Case Study: "How Facebook automated accessibility improvements using AI".
- **Think-Pair-Share**: *"How could AI tools reduce onboarding time for new coders?"*

#### **Hands-On AI Tool Demo (10 mins)**
- Live Demo: Solve a basic Python task using GitHub Copilot (e.g., create a sorting function with comments).
- Highlight **AI-generated vs. manual code efficiency** via a shared Replit IDE.

#### **Guided Hands-On Coding (25 mins)**
**Activity:** *Iterative Workflow Practice*
1. **Plan**: In pairs, design a simple calculator app in Python (user input, error handling).
2. **Generate with AI**: Use Copilot to scaffold the code (20 min).
   - Scaffolded template provided for beginners.
3. **Modify**: Debug and optimize with peer review.
4. **Repeat**: Document improvements in a Padlet reflection board.

**Support:**
- Worked example (starter code) for struggling learners.
- Challenge: "Generate a non-trivial test case for your partner's code."

#### **Group Presentations & Peer Review (10 mins)**
Each pair shares their workflow modifications using 1-slide summaries. Peers vote on "Most Creative AI Use" via Mentimeter.

---

### **Synthesis & Closure (10 minutes)**
**Post-Test (3 questions):**
1. Rank AI code tools on a 1–5 scale for usefulness in your projects.
2. Short answer: Describe one way AI might *hurt* software quality.
3. Reflect: "What surprised you most about today's class?"

**Real-World Connection:**
- Show Microsoft's AI-powered Power Apps interface for democratized UX design.

**Preview Next Session:**
- Homework: Research AI's role in software ethics (bias in training data, job market impact).

---

## 4. Assessment Methods

### **Formative (In-Class):**
1. Pre-/Post-Test Comparison (Knowledge Gains on AI capabilities).
2. Mentimeter poll responses (peer voting during presentations).
3. Exit Tickets: Padlet reflections ("I used to think..., but now I know...").

### **Summative (Post-Class):**
**Individual Assignment**: Analyze a real-world AI development tool (e.g., Amazon CodeWhisperer) using a **provided rubric**:
- Relevance to traditional challenges (30%)
- Workflow integration (30%)
- Ethical critique (40%)

## 6. Required Resources
- **LMS**: Canvas/LMS with pre-test/post-test module
- **Tools**: GitHub Copilot (trial access), Replit IDE, Mentimeter, Padlet
- **Media**: Animated debugging comparison graphic, GitHub blog PDF
- **Physical**: None required (fully digital)

---

## 7. Differentiation & Inclusivity
**For Struggling Students:**
- Provide pre-scaffolded starter code templates.
- Allow 2-person teams for hands-on activities.

**For Advanced Learners:**
- Challenge: "Use AI to generate test cases for your code."

**Multilingual Support:**
- Provide code comments in Spanish/Chinese via Copilot language settings.
- Subtitled demo video (YouTube auto-translate available).

**Disability Access:**
- Keyboard shortcuts for Copilot demonstrated for motor-impaired users.

---

## 8. Reflection & Improvement
**Success Metrics:**
- >70% pre-test to post-test score improvement
- 80% engagement in hands-on activity (observed)
- Peer votes evenly distributed (indicating balanced participation)

**Feedback**:
- Collect via anonymous LMS survey (3 questions):
  1. What tool features confused you most?
  2. Would you use AI tools for homework after this class?

**Improvements for Next Iteration:**
- Add 5-minute breakout room tutorials for Copilot basics.
- Introduce a "code quality checklist" for ethical critiques.
