# Modern Software Developer Lesson Plan

## 1. Intended Learning Outcomes (ILOs)
By the end of this session, students will be able to:
- Analyze the evolution of software development workflows from traditional to AI-enhanced models using established software engineering frameworks
- Apply at least two AI-assisted coding tools (GitHub Copilot, Cursor) to specific development stages (ideation, coding, debugging)
- Evaluate the effectiveness of AI tools in addressing traditional software engineering challenges (code complexity, technical debt)
- Synthesize a personalized workflow integrating human expertise with AI-powered development tools

## 2. Pre-Class Preparation
- **Pre-reading**: "The State of AI in Software Development" (2023 Microsoft Research Paper) + GitHub Copilot case study
- **Video**: "AI Pair Programming with Cursor AI" (10-min demo)
- **Pre-test** (Kahoot): 5-question quiz covering core concepts
- **Guiding questions**:
  - How might AI change the traditional developer role?
  - What ethical concerns should we consider with AI-generated code?
  - How could these tools impact software development accessibility?

## 3. Teaching & Learning Activities

### Introduction (12 minutes)
- **Hook**: "Will AI take over developers' jobs?" poll with live results (Mentimeter)
- Pre-test discussion: Highlight key misconceptions (70% correct on technical debt questions)
- Real-world connection: Demo Microsoft's AI-driven DevOps pipeline for Azure

### Development (63 minutes)
**Segment 1: Framework Evolution** (15 minutes)
- Interactive lecture: Traditional → CI/CD → AI-enhanced workflow diagram
- Animated illustration: "[Animated Visualization: The AI-Enhanced Coding Loop]"
- Think-pair-share: Compare waterfall vs AI-assisted development models

**Segment 2: Tool Demonstration** (20 minutes)
- Live demo:
  1. Planning with ChatGPT-4 for a Python web scraper
  2. Code generation with GitHub Copilot [Tool: GitHub Copilot demo access]
  3. Debugging with Cursor AI
- Digital flashcards: "[Flashcards: AI Developer Toolset - 10 key commands]"

**Segment 3: Case Study Analysis** (25 minutes)
- Small groups:
  - "Build an e-commerce checkout system using AI tools within 30 minutes"
  - Constraints: Accessibility requirements, cross-browser compatibility
- Peer teaching: Group presentations with critique using [Checklist: AI-Enhanced Solution Evaluation]

**Segment 4: Formative Assessment** (3 minutes)
- Real-time quiz: [Quiz: AI Tool Workflow Analysis - 5 questions]

### Synthesis & Closure (15 minutes)
- Post-test vs pre-test comparison
- Gallery walk: Group workflow diagrams on sticky notes
- Reflective discussion: "How has your understanding of developer roles changed?"
- Preview next session: "Ethical implications of AI-generated code in enterprise environments"

## 4. Assessment Methods

### Formative Assessment
- Pre/post test score comparison (Knowledge gain target: +30% average)
- Exit ticket: "Explain one way AI tools can address technical debt in 50 words"
- Live code review: Instant feedback during tool practice

### Summative Assessment
**Individual Assignment: "AI-Enhanced Development Workflow Blueprint"**
- Requirements:
  - 2000-word analysis of traditional vs AI workflow
  - Implementation plan for mid-sized development team
  - Ethical considerations section
- Rubric:
  - Accuracy of workflow comparison (40%)
  - Practicality of implementation plan (30%)
  - Ethical analysis depth (20%)
  - Innovation in tool integration (10%)

## 5. Constructive Alignment Matrix

| Learning Outcome | Teaching Activity | Assessment Method |
|------------------|-------------------|-------------------|
| Analyze evolution | Interactive lecture with framework comparison | Assignment: Workflow analysis |
| Apply tools | Tool demonstrations and case study practice | Hands-on sandbox exercises |
| Evaluate effectiveness | Group debate on tool limitations | Exit ticket critical reflection |
| Synthesize workflow | Gallery walk with peer critique | Assignment: Implementation plan |

## 6. Required Resources
- GitHub Copilot trial licenses
- Cursor AI access
- Cloud IDE platform (Gitpod)
- Mentimeter for live polling
- Padlet wall for idea sharing
- Animated loop visualization prototype [Interactive Tool: SVG-based workflow simulator]
- Code snippets repository: GitHub Classroom assignment

## 7. Differentiation
- **Beginners**: Step-by-step tool guides with screenshot annotations
- **Advanced learners**: Additional challenge: Reverse-engineer production GitHub repositories
- **Visual learners**: Color-coded workflow diagrams with accessibility overlays
- **Language support**: Subtitled videos + multilingual concept maps
- **Accessibility**: Screen-reader compatible code editors and keyboard navigation

## 8. Evaluation & Improvement
- **Success indicators**:
  - Tool proficiency: 70% completion rate of coding challenges
  - Cognitive engagement: >75% participation in discussions
- **Feedback mechanisms**:
  - Post-session survey with Net Promoter Score
  - Follow-up alumni interview at semester end
- **Potential improvements**:
  - More diverse case studies
  - Integration of version control tools in workflow exercises
  - Expand ethics discussion to include code ownership and IP implications
