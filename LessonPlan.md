# University Lesson Plan: Intelligent TPACK Framework in Teacher Capacity Building

---

## 1. Intended Learning Outcomes (ILOs)
By the end of this lesson, students will be able to:
**ILO 1**: Analyze how AI tools enhance Technological Pedagogical Content Knowledge (TPACK) components
**ILO 2**: Design a lesson plan integrating Intelligent TPACK framework elements
**ILO 3**: Evaluate ethical implications of AI integration using the TPACK framework

---

## 2. Pre-Class Preparation (Flipped Learning Component)
**Pre-Reading**:
- Koehler & Mishra (2005) TPACK framework foundational paper ([PDF])
- Case study: "Intelligent TPACK Implementation in High School STEM Classrooms" ([PDF])

**Pre-Test (Mentimeter Poll)**:
[Quiz: AI Integration in TPACK - 5 scenario-based questions]
Sample question: *Which TPACK component would be most enhanced by using an adaptive learning platform for math instruction?*

**Guiding Questions**:
1. How might AI tools strengthen content-pedagogy connections in your teaching context?
2. What ethical considerations arise when integrating AI into TPACK framework?

---

## 3. Teaching & Learning Activities

### **Introduction (10-12 minutes)**
**Hook Activity (5 min)**:
- Analyze a case study excerpt showing both successful and problematic AI integration examples
- Poll: Which case demonstrates authentic TPACK enhancement? [Mentimeter: Multiple Choice Poll]

**Pre-Test Discussion (5 min)**:
- Review common misconceptions identified in pre-test responses
- Visual concept map showing AI's role within TPACK components ([Animated Concept Map: Intelligent TPACK])

**Real-World Connection (2 min)**:
- Brief video clip: K-12 classroom using AI tools with TPACK alignment
- Quick "I notice/I wonder" protocol (Padlet board for collaborative reflection)

---

### **Development Activities (63-66 minutes)**

**Activity 1: Interactive Lecture + Think-Pair-Share (15 min)**
- Break down TPACK framework with AI overlay using the [TPACK 2.0 Animated Visualization]
- Prompt: Identify a teaching strategy where AI could strengthen two TPACK components simultaneously

**Activity 2: Small Group Design Challenge (20 min)**
- Groups of 4-5 design an AI-enhanced TPACK lesson plan using this template:
[TPACK Design Canvas: Content-Knowledge Component | Pedagogical Approach | Tech Integration | AI Application]
- Provide worked example for differentiation

**Activity 3: Peer Critique Circles (15 min)**
- Rotating station review: Leave critique notes using 2 stars and 1 wish protocol
- Digital flashcards for key terminology reinforcement [Kahoot: Intelligent TPACK Vocabulary]

**Activity 4: Ethical Debate Scenario (10 min)**
- Analyze conflicting stakeholder perspectives in this scenario:
[Scenario: "Your district mandates AI grading tools that conflict with your content specialty"]
- Structured Socratic seminar framework with role cards

**Activity 5: Formative Check (5 min)**
- One-minute paper: How has your understanding of teacher capacity changed after today's activities?

**Class Flow Notes**:
- 5-minute mid-class stretch break between activities 2 and 3
- Digital collaboration tools available for remote participants (Padlet/Miro boards)

---

### **Synthesis & Closure (12-15 minutes)**
**Post-Test Comparison (5 min)**:
- Same question format as pre-test to measure learning gains

**Reflective Discussion (5 min)**:
- Create a class "I can" statement wall: Post-lesson TPACK-AI capabilities

**Next Session Preview (2-3 min)**:
- Connect to upcoming workshop on personalized learning pathways using Intelligent TPACK

---

## 4. Assessment Methods

### **Formative Assessment**
- Pre-Post Test comparison (same question bank)
- Peer critique rubric focusing on ILO alignment
- One-minute paper analysis using coding rubric:
[Conceptual Understanding | Practical Application | Critical Thinking]

### **Summative Assessment**
**Assignment**: "Intelligent TPACK Implementation Prospectus" (Due next week)
Rubric:
| Criteria | Exemplary (4) | Proficient (3) | Developing (2) |
|---|---|---|---|
| TPACK Framework Integration | Seamless component integration | Clear connections | Fragmented application |
| AI Functionality Match | Optimal pedagogical alignment | Appropriate use | Misaligned tools |
| Ethical Consideration | Comprehensive, nuanced analysis | Basic ethical awareness | Insufficient treatment |
