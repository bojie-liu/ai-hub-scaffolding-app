**University Lesson Plan: The Modern Software Developer**

---

### 1. Intended Learning Outcomes (ILOs)
By the end of this session, students will be able to:
1. **Analyze** the evolution of software development workflows using AI tools compared to traditional methods (Bloom: Analyze).
2. **Evaluate** the ethical, technical, and accessibility implications of AI-driven software engineering (Bloom: Evaluate).
3. **Apply** AI-powered tools (e.g., GitHub Copilot, low-code platforms) to solve a basic programming challenge (Bloom: Apply).
4. **Create** a prototype of a simple application using iterative plan-generate-modify cycles (Bloom: Create).

---

### 2. Pre-Class Preparation
**Pre-Reading/Video (15 mins):**
- Watch *"The State of Software Development in 2024"* (YouTube, ~10 mins): Link to [Microsoft MVP AI Toolkit Demo Playlist](https://www.youtube.com/playlist?list=PLxyz123456789).
- Skim article: *"Democratizing Code: How AI is Reshaping the Developer Workforce"* (Medium, ~5 mins).

**Pre-Test (5 Questions via LMS):**
1. What is the primary difference between traditional "0-1" coding and AI-augmented workflows?
2. Name two ethical risks of AI-generated code.
3. True/False: GitHub Copilot guarantees secure, bug-free code.
4. Provide an example of a low-code/no-code tool.
5. How might AI tools increase diversity in software development?

**Guiding Questions:**
- How would you explain AI's role in reducing technical barriers to programming?
- Should developers always trust AI-generated code? Why or why not?

---

### 3. Teaching & Learning Activities

#### **Introduction (20 mins)**
1. **Hook (5 mins):**
   - Pose the question: *"Will AI replace developers?"*
   - Live Mentimeter poll: "Agree/Disagree" with results displayed anonymously.

2. **Pre-Test Discussion (10 mins):**
   - Review common misconceptions (e.g., AI replacing humans; tooling accessibility).
   - Show aggregate pre-test results to address gaps.

3. **Real-World Connection (5 mins):**
   - Case study: Netflix's use of AI for scalable testing frameworks.

---

#### **Development Activities (120 mins)**

**Activity 1: Interactive Lecture + Think-Pair-Share (30 mins)**
- **Topic:** Evolution of workflows (0-1 vs. iterative plan/generate/modify).
- Use animated flowcharts to compare:
  - Handwritten code (1990s-2010s) vs. AI-assisted code (2024).
- **Think-Pair-Share Prompt:**
  - *"How might iterative workflows impact project timelines for startups vs. enterprises?"*

**Activity 2: Group Case Study + Padlet Discussion (30 mins)**
- Divide students into 18 groups of 5.
- **Instructions:** Use the Padlet link [provided in External Link Module] to collaborate:
  1. Analyze a scenario (e.g., "A non-technical entrepreneur builds an MVP with no-code tools").
  2. Identify pros/cons (e.g., speed vs. security risks).
- Groups post summaries to Padlet for peer review.

**Activity 3: AI Tool Demo + Guided Practice (30 mins)**
- Live demo of GitHub Copilot for Python script optimization.
- **Scaffolded Task:**
  - Step 1: Instructor shows basic code completion.
  - Step 2: Students adapt demo code to generate a Fibonacci sequence.
  - Step 3: Peer pair-check code for logical errors.
- Provide access to free-tier [GitHub Copilot trial](https://github.com/features/copilot).

**Activity 4: Ethics Role-Play + Poll (30 mins)**
- Assign roles (developer, end-user, company manager, cybersecurity expert).
- **Scenario:** AI-generated code introduces a privacy violation.
  - Debate responsibilities and mitigation strategies.
- Close with a Mentimeter multiple-choice poll on "Who owns AI-generated code?"

---

#### **Synthesis & Closure (20 mins)**
1. **Post-Test (5 mins):**
   - Identify key changes in software engineering workflows since 2010.
   - Explain 1 ethical concern to discuss with a client advocating full AI reliance.

2. **Reflective Discussion (10 mins):**
   - Ask: *"How will AI-augmented tools align or conflict with your career goals?"*
   - Display Padlet group summaries for whole-class analysis.

3. **Preview Next Session (5 mins):**
   - Introduction to prompt engineering for code generation.

---

### 4. Assessment Methods

#### **Formative Assessment**
- **Mentimeter Polls:** Track real-time understanding of ethical debates.
- **Padlet Submissions:** Quality of case study analysis (e.g., depth of pros/cons).
- **Exit Ticket (1-Minute Paper):**
  - *"The most surprising thing I learned about AI's impact on developers today"*

#### **Summative Assessment**
**Take-Home Assignment (Due in 1 Week):**
- Task: Use AI tools to build a simple web app (e.g., a personal portfolio).
- Rubric:
  - Functionality (30%)
  - Code quality/revisions (30%)
  - Reflection on ethical considerations (40%)
