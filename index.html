📊 Place Value in Numbers

Primary 3 Mathematics | Duration: 60 minutes | Ages 8-9 | Class Size: 30 students
Current Role: Student

📚 Lesson Overview

This comprehensive lesson introduces Primary 3 students to place value in 3-digit numbers (up to 999) using the Scaffolded Instruction approach with the Concrete-Pictorial-Abstract (CPA) method.

Students will explore place value through hands-on manipulatives, visual representations, and abstract reasoning, building from identification through comparison to real-world application.

👨‍🏫 Teacher Notes

Pedagogy Focus: Scaffolded Instruction with CPA (Concrete-Pictorial-Abstract)

  • Begin with diagnostic assessment to identify misconceptions
  • Use "I Do → We Do → You Do" gradual release model
  • Ensure 80%+ students achieve exit ticket mastery
  • Monitor for common errors with zeros (e.g., 402, 308)
