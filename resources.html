External Tool Integration

Purpose: Poll students on diagnostic quiz questions to identify common misconceptions

Learning Objective: Assess prior knowledge and surface errors for discussion

Step-by-Step Instructions:

  1. Go to Mentimeter.com and create a free account
  2. Click the "New presentation" button
  3. Choose "Multiple Choice" question type
  4. Enter question: "In the number 240, how many tens are there in total?"
  5. Add options: (a) 2, (b) 4, (c) 24
  6. Click "Present" and share the code with students
  7. Students join at menti.com using the code
  8. Display results live and discuss common misconception (choosing "4" instead of "24")

Purpose: Quick comprehension check on comparing and ordering 3-digit numbers

Learning Objective: Apply place value reasoning to order numbers correctly

Step-by-Step Instructions:

  1. Go to Kahoot.com and create a free teacher account
  2. Click "Create" in the top menu, then "New Kahoot"
  3. Choose "Quiz" type
  4. Add question: "Order these numbers from smallest to largest: 471, 417, 691, 174"
  5. Set correct answer: "174, 417, 471, 691"
  6. Set timer: 60 seconds
  7. Click "Done" and then "Play"
  8. Choose "Teach" mode and project the game PIN
  9. Students join at kahoot.it and enter the PIN
  10. Review leaderboard to identify students who need extra support

Purpose: Pre-lesson introduction to place value concepts (flipped classroom component)

Learning Objective: Build foundational understanding before hands-on activities

Step-by-Step Instructions for Students:

  1. Go to Khan Academy Place Value
  2. Watch "Place Value: Hundreds, Tens, and Ones" (3 minutes)
  3. Take notes on key vocabulary: hundreds, tens, ones, place value
  4. Complete the diagnostic quiz in your homework packet
